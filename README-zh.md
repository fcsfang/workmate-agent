# Workmate Agent

> **目标会被记住，但行动需要被看住。**

Workmate Agent 是一个本地优先的个人生产力 Agent。  
它会持续看着你正在做的事，判断这件事是不是在推进你的长期目标，并在你走神、拖延或偏航的瞬间主动出现——把你拉回到该做的事情上。

它不是又一个 Todo App，也不是一个只会被动回答问题的聊天机器人。  
Workmate 更像一个长期在场的监督者：它记得你要完成什么，只是为了能看清你现在是不是真的在做；它在你专注时保持安静，在你掉线时把你叫回来。

## 为什么需要 Workmate？

很多长期目标不是因为不会做而失败，而是败在更日常、更隐蔽的瞬间：

- 明明知道目标重要，却在一次次"先刷一下手机"里悄悄偏航；
- 计划写得很认真，执行的时候却总被某个无关紧要的事情拽走注意力；
- 想要更专注、更自律，却没有人在你真正走神的那一刻，告诉你"现在偏了"；
- Todo 列表记着"要做什么"，却没有人确认它有没有真的发生；
- 就连和 AI 聊过的计划，下一次对话也常常从零开始，好像从没发生过。

传统 Todo 工具擅长保存"要做什么"。  
普通聊天机器人擅长回答"现在问什么"。

但分心和拖延，从来不是缺一个记录工具，而是缺一个会在你走神时出声的人。真正缺的是一个持续闭环：

**看见行动 → 识别偏航 → 主动提醒 → 回到主线 → 记得这一切，以便明天接得上。**

Workmate Agent 正是围绕这个闭环构建的个人生产力 Agent。

## 它想成为怎样的 Agent？

Workmate 的愿景不是替用户完成一切，也不是简单地催促用户做事。

它希望成为一个持续盯紧你专注度的监督者：

- 理解你此刻正在做什么，判断它是否在推进当前目标；
- 在任务停滞、注意力偏航或承诺临近时及时介入；
- 帮你把一次次零散的专注，攒成稳定的行动节奏；
- 在长期目标上，逐步替你养成更自律的生活方式；
- 而为了做到这些，它需要先记得你的目标——记忆是手段，不是目的。

它关注的不只是一次任务有没有完成，而是用户能不能在长期目标上持续保持方向感、专注度和行动力。

## 核心体验

### 1. 行动真的被看见

真正决定目标是否推进的地方，往往不是聊天窗口，而是屏幕。

Workmate 的视觉监督模块会结合当前目标理解屏幕内容。它不只判断你打开了什么应用，还会分析眼前活动是否正在推进当前任务，并结合近期轨迹区分一次临时切换和持续偏航。

**当前目标 × 屏幕语义 × 行为轨迹 → 静默、同行或拉回。**

你专注推进任务时，它保持安静。  
你进入与目标相关的工作场景时，它会给出同行式反馈。  
你长时间偏离当前目标时，它会生成一次可追踪的监督事件。

### 2. 偏航时，及时拉回

知道目标重要和真的在做这件事，中间常常隔着一次又一次没被察觉的分心。

Workmate 会持续观察几类信号：

- 当前任务是否长时间没有推进；
- 你是否持续停留在与目标无关的屏幕活动中；
- 专注时段是否已经结束；
- 承诺是否临近或逾期；
- 最近行为轨迹是否显示出持续偏航。

这些信号会被转化为可追踪的监督事件，进入完整生命周期：创建、提醒、确认、延后、关闭或完成。

目标不会再悄无声息地被日常事务覆盖，注意力也不会在无感切换中慢慢丢失——因为总有人在看着，并在偏得太远之前出声。

### 3. 目标不会掉线

监督要成立，前提是 Workmate 得先记得你到底要做什么。

计划一旦交给 Workmate，就不再只是一句话随风而散。它会持续维护任务状态：主任务、子任务、当前进展、阻塞原因、下一步行动和未关闭承诺都会被结构化保存。

即使刷新页面、重启服务，或者隔几天重新回来，任务仍然可以从原来的位置继续——你不需要重新解释你之前做到哪里、这件事为什么重要、下一步该干什么。

这条记忆主线，是它能持续判断"你有没有偏"的全部依据。

![持续更新的任务主线](docs/assets/task-lifecycle.png)

### 4. 它慢慢摸清你的注意力规律

自律不是靠一次提醒养成的，而是靠持续被看见、被反馈，慢慢校准出来的。

Workmate 保存的不只是任务和对话，还包括重复出现的行为模式与阶段性反思：它可能会发现你总在下午三点后开始走神，或者某类任务总是被一拖再拖。

这些发现不会停留在原始记录里——只在真正相关时，才会重新进入对话，变成一句具体的提醒，而不是一堆陈旧的历史。

这正是自律养成的起点：先被持续看见，才有持续调整的可能。

## 技术实现

Workmate Agent 的产品体验由一套完整的 Agent 运行链路支撑：

- **主动监督事件机制**：将停滞、偏航、承诺临近等信号转化为可追踪事件；
- **多模态屏幕理解**：通过视觉模型分析当前屏幕与目标之间的关系；
- **任务生命周期管理**：维护任务、子任务、进展、阻塞、下一步与事件流；
- **分层记忆系统**：区分短期上下文、任务状态、长期画像、阶段反思与向量记忆；
- **Schema 驱动的内部状态工具**：让 Agent 可以结构化地读写任务和记忆，而不是只生成自然语言；
- **本地优先架构**：任务、记忆、索引和运行数据默认保存在本机；
- **FastAPI 服务层**：提供 Web 交互、流式响应和 OpenAPI 接口；
- **自动化测试与固定评估集**：用于验证 Agent 行为在不同场景下的稳定性。

```bash
conda run -n agent pytest
conda run -n agent python evals/run_eval.py
```

## 数据与隐私

Workmate 默认以本地优先方式运行。

- 任务、对话、画像、长期认知和向量索引默认保存在本机；
- 使用外部模型时，必要上下文会发送给所配置的模型服务商；
- 启用视觉监督后，临时截图会发送给视觉模型，并在分析完成后从本地删除；
- API Key、运行时记忆、屏幕截图和本地索引不会提交到 Git。

你可以随时清除全部本地记忆：

```bash
# 先停止正在运行的 Workmate
./scripts/clear_memory.sh
```

## 快速开始

要求 Python 3.12+。  
推荐使用 Conda，也支持自动创建本地 `.venv`。

```bash
git clone https://github.com/fcsfang/workmate-agent.git
cd workmate-agent
cp .env.example .env
```

在 `.env` 中填写 OpenAI 兼容模型配置：

```env
LLM_MODEL_ID=moonshotai/kimi-k2.6:free
LLM_API_KEY=your-api-key-here
LLM_BASE_URL=https://openrouter.ai/api/v1
```

启动服务：

```bash
./run.sh
```

默认地址：

- Web 页面：`http://127.0.0.1:7860`
- OpenAPI：`http://127.0.0.1:7860/docs`
- 自定义端口：`WORKMATE_PORT=7861 ./run.sh`
- 停止服务：在运行终端按 `Ctrl+C`

## 项目边界

Workmate 当前是一个本地优先、单用户的个人生产力 Agent。

它不会替你完成具体工作，也不是一个通用自动化执行器。它更像一个长期盯着你专注度的监督者：记得主线、看见行动，并在你即将掉线时把你拉回来。

它的目标不是制造更多提醒，而是帮你在长期目标上，逐步活成一个更自律的人。
