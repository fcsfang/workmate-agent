
### 用户

有拖延症、注意力不集中问题的工作者。

初次开始某个项目，需要规划切实可行的实施步骤的工作者。

### 输入

用户今天要完成的事情/要达到的目标/或者仅仅是某个困惑（只提供方法、不提供具体解决方案，一句话：帮助用户做事）

### 输出

给用户方法，比如可以尝试某个工具、给AI的提示词等等

判断用户是否按计划执行，是否走神、注意力不集中

记录时间与进度，判断用户是否高效

给出可能的下一步行动


### 需要解决什么问题？

> 让AI能够像长期工位搭子一样，基于历史记录监督用户持续推进长期目标。

1. 感知时间，建立时间与任务进度之间的对应关系
2. 听取汇报并分析进度情况，鼓励或指出问题，给出下一步规划(好像Prompt就可以实现)
3. 记忆系统，记住我每时每刻做的，每天做的、每周做的、每月做的
4. 主动执行发出每日任务规划，每日总结报告、每周总结报告、每月总结报告
